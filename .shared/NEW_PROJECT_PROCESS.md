# 🚀 신규 프로젝트 시작 프로세스 (Claude Code용)

**목적**: 신규 프로젝트를 시작할 때 항상 따라할 표준 프로세스

> **중요**: 이것은 "자동"이 아닙니다. 신규 프로젝트 시작 시 이 파일을 참조하거나, 나(Claude)에게 명시적으로 지시해야 합니다.

---

## 📋 프로세스 (4단계, 15분)

### Step 1️⃣: 프로젝트 타입 결정 (30초)
```bash
.shared/QUICK_SELECT.md 열기
↓
당신의 프로젝트 타입 찾기 (CLI / 웹앱 / Agent / 데이터 / 영상)
↓
✅/⭐ 표시된 스킬만 메모
```

### Step 2️⃣: 필요한 스킬 README 읽기 (5-20분)
```bash
.shared/[필요한 스킬]/README.md 읽기
↓
핵심 원칙/개념 파악
↓
메모 작성
```

### Step 3️⃣: 프로젝트 CLAUDE.md 작성 (5분)
```bash
# [프로젝트명]

## Coding Process
.shared/QUICK_SELECT.md 기준으로 필요 스킬 적용

## Principles [필요한 스킬별로]
[Step 2에서 읽은 내용 정리]

## Notes
[프로젝트 특화 규칙]
```

### Step 4️⃣: 작업 시작
```bash
나(Claude): CLAUDE.md 읽고 프로세스 준수
당신: 지시 및 피드백
```

---

## ⚡ 신규 프로젝트 시작 명령어 (권장)

### 옵션 A: 명시적 지시 (확실함)
```
당신: "새로운 프로젝트를 시작해.
      QUICK_SELECT.md → [필요한 스킬] → CLAUDE.md 작성 프로세스로 진행해줘"
나: Step 1 → 2 → 3 → 4 진행
```

### 옵션 B: 프로젝트 타입 명시
```
당신: "새로운 웹앱 프로젝트를 시작해"
나: QUICK_SELECT.md에서 "웹앱" 행 참조 → ① Karpathy + ⭐ Superpowers 진행
```

### 옵션 C: 프로젝트 구조 먼저 제공
```
당신: [프로젝트 폴더 제공]
나: README.md 자동 읽기 → .shared 프로세스 자동 판단 (상황 따라)
```

---

## 🎯 명심할 점

| 상황 | 내 동작 | 당신이 해야 할 것 |
|------|-------|-----------------|
| 명시적 지시 O | ✅ 프로세스 따름 | 지시하기 (권장) |
| 명시적 지시 X | ❌ 자동 프로세스 안 함 | QUICK_SELECT.md 참조해서 지시 |
| CLAUDE.md 있음 | ✅ 그대로 따름 | - |
| CLAUDE.md 없음 | ⚠️ 기본 프로세스 | CLAUDE.md 작성 지시 |

---

## ✅ 체크리스트 (신규 프로젝트마다)

신규 프로젝트 시작 전 확인:
- [ ] QUICK_SELECT.md에서 프로젝트 타입 찾았는가?
- [ ] 필요 스킬이 명확한가?
- [ ] 나(Claude)에게 "이 스킬들로 진행해줘" 명시했는가?
- [ ] CLAUDE.md를 작성했거나 작성할 준비가 되었는가?
- [ ] 불필요한 스킬 README는 무시하기로 결정했는가?

---

## 💾 메모: 이 프로세스를 자동화할 수 있을까?

### 현재 불가능한 것:
- ❌ 나(Claude)가 자동으로 .shared를 참조
- ❌ 나(Claude)가 자동으로 QUICK_SELECT.md 읽기
- ❌ 나(Claude)가 자동으로 프로세스 결정

### 앞으로 가능할 수 있는 것:
- ⚠️ 메모리에 저장 → 향후 대화에서 참조
- ⚠️ .claude/settings.json의 hooks → "새 프로젝트 시작 시 이 프로세스 따르기"
- ⚠️ 프로젝트 템플릿 → 신규 프로젝트 생성 시 자동으로 CLAUDE.md 포함

---

**핵심**: 이것은 "자동"이 아니라 "표준 프로세스"입니다. 
당신이 지시하거나, 메모리/CLAUDE.md에 명시하면 나는 따릅니다.
