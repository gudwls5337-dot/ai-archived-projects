## 🚨 토큰 낭비 주요 지점

### 1️⃣ **agentmemory README (86KB = ~10,000 토큰)** 🔴
**문제**: 매우 상세하지만 대부분의 프로젝트에는 불필요
- 실제 필요 빈도: 20% (Agent 프로젝트만)
- 우발적 읽기로 인한 낭비: 매우 큼

**해결책**:
```markdown
❌ "agentmemory 전체 README를 읽기"
✅ "agentmemory/README.md의 첫 200줄 + 설치 섹션만"
```

### 2️⃣ **Understand-Anything README (16KB = ~2,000 토큰)** ⚠️
**문제**: 상세하지만 대부분 프로젝트에는 불필요
- 실제 필요 빈도: 10% (복잡한 코드베이스 분석만)
- 우발적 읽기 가능성: 중간

**해결책**:
```markdown
❌ "모든 프로젝트에서 이 README 확인"
✅ "필요할 때만 (복잡한 레거시 시스템 분석) 찾아 읽기"
```

### 3️⃣ **Superpowers README (8.3KB = ~1,000 토큰)** ⚠️
**문제**: 50% 프로젝트에는 필요하지만, 간단한 프로젝트에는 낭비
- 웹앱/CLI: 필요 (1000 토큰 낭비 가능)
- Agent: 필요 (1000 토큰 가치 있음)
- 간단한 유틸: 불필요 (1000 토큰 낭비)

**해결책**:
```markdown
프로젝트가 "간단"하면 건너뛰기
프로젝트가 "복잡"하면 읽기
```

### 4️⃣ **Karpathy Guidelines README (2.4KB = ~250 토큰)** ✅
**평가**: 모든 프로젝트에 필수
- 크기 작음
- 항상 가치 있음
- 토큰 낭비 없음

## ⚠️ 현재 문제점 및 개선안

### 현재 설정의 문제:
1. **agentmemory가 너무 크다** (86KB)
   - 대부분 프로젝트에는 불필요
   - 우발적 읽기 시 10,000 토큰 낭비 가능

2. **5개 스킬 모두 나열**
   - 신규 프로젝트에서 "모든 README를 읽어야 하나?" 하는 불안감 유발
   - 실제로는 1-3개만 필요

3. **선택 가이드가 명확하지 않음**
   - "이 스킬이 내 프로젝트에 필요한가?" 판단 어려움

### 개선안:

#### ✅ 개선 1: `.shared/QUICK_SELECT.md` 추가
프로젝트 타입 → 필수 스킬 매핑 (한눈에)

```markdown
# 스킬 선택 매트릭스

| 프로젝트 | ① Karpathy | ② Superpowers | ③ agentmemory | ④ Understand | ⑤ claude-video |
|---------|-----------|--------------|--------------|--------------|----------------|
| CLI/유틸 | 필수 | ❌ | ❌ | ❌ | ❌ |
| 웹앱 | 필수 | 강추 | ❌ | ❌ | ❌ |
| Agent | 필수 | 필수 | 강추 | ⚠️ | ❌ |
| 데이터 | 필수 | ⚠️ | ❌ | 강추 | ❌ |
| 영상 | 필수 | ❌ | ⚠️ | ❌ | 필수 |
```

#### ✅ 개선 2: agentmemory "요약 버전" 만들기
- 전체 86KB → 요약 2-3KB (500 토큰)
- 필요 시에만 전체 README 읽기

#### ✅ 개선 3: QUICK_START.md 단순화
현재: 너무 친절함 (실제 필요 정보는 2분 분량)
→ "정말 필요한 것"만 남기기
