================================================================================
📺 YouTube 쇼츠 정보 추출 도구 - 사용 가이드
================================================================================

✅ 이 도구는 YouTube 채널의 쇼츠 영상 정보를 자동으로 추출합니다.

📊 추출되는 정보:
  • 제목, 조회수, 설명, 해시태그
  • 영상 길이, 업로드 날짜
  • Whisper 음성 인식 자막 (핵심!)
  • 영상 URL

================================================================================
🚀 사용 방법 (3가지)
================================================================================

방법 1️⃣: 웹 UI (가장 쉬움) ⭐⭐⭐
─────────────────────────────────

1. 터미널(명령프롬프트)를 열고 다음을 입력:
   python main.py

2. 브라우저에서 다음 주소 접속:
   http://localhost:8001/docs

3. "POST /scrape" 버튼 클릭

4. "Try it out" 클릭

5. 다음을 입력:
   • channel_url: https://www.youtube.com/@채널명
   • max_results: 5 (또는 원하는 개수)
   • sort_by: newest (또는 popular)
   • output_format: xlsx (또는 csv/json)

6. "Execute" 클릭

7. 결과 링크를 클릭하면 파일 다운로드됨

⏱️ 예상 시간: 5개 = 3-5분, 10개 = 5-10분


방법 2️⃣: 명령어 (빠르고 간단)
─────────────────────────────────

1. 터미널을 열고 다음 명령어 입력:

   python scraper.py --url "https://www.youtube.com/@채널명" --max 5 --format xlsx

   예시:
   python scraper.py --url "https://www.youtube.com/@K-전성시대" --max 5 --format xlsx

2. 완료되면 파일이 data/output 폴더에 저장됨

3. 파일을 열어서 확인


방법 3️⃣: 배치 파일 (가장 편함)
─────────────────────────────────

1. 실행.bat 파일을 더블클릭

2. URL을 입력하고 Enter

3. 자동으로 처리됨

⏱️ 시간 예상
================================================================================

Whisper 모델 로드 (첫 실행):
  약 1-2분 (자동 다운로드)

영상별 처리 시간:
  • 30초 영상: 30-45초
  • 60초 영상: 45-60초

총 처리 시간:
  • 1개: 1-2분 (모델 로드 포함)
  • 5개: 3-5분
  • 10개: 5-10분
  • 50개: 25-50분

💡 팁: 처음엔 5개로 시작한 후, 필요하면 늘리세요!

================================================================================
🐛 문제 해결
================================================================================

Q: "포트 8001이 이미 사용 중"이라는 오류가 나요
A: 이전 프로그램이 여전히 실행 중입니다. 다음을 입력하세요:
   netstat -ano | findstr :8001
   그리고 나오는 PID로 프로세스를 종료하세요.

Q: Whisper 경고 메시지가 나요 (FP16 관련)
A: 경고일 뿐, 오류가 아닙니다. 계속 진행하면 됩니다.

Q: 자막이 추출 안 될 때가 있어요
A: 다음 이유 때문입니다:
   • 영상이 음성이 거의 없음 (배경음악만 있을 수 있음)
   • 음성이 너무 작거나 안 들림
   • 인터넷 연결 느림

Q: 너무 오래 걸려요
A: 음성 인식은 시간이 걸립니다. 다음을 시도하세요:
   • 개수를 줄이기 (50개 → 5개)
   • CPU가 좋은 컴퓨터에서 실행
   • 다른 프로그램 종료

Q: 파일이 깨져서 나와요
A: 호환성 문제입니다. 다음을 시도하세요:
   • CSV 형식 사용 (--format csv)
   • 다른 Excel 버전 사용
   • Google Sheets에서 열기

================================================================================
📋 명령어 참고
================================================================================

CLI 옵션:
  --url         : YouTube 채널 URL (필수)
  --max         : 추출할 개수 (기본: 50)
  --sort        : 정렬 방식 (newest 또는 popular)
  --format      : 저장 형식 (csv, json, xlsx)
  --verbose     : 상세 로그 출력

예시:
  python scraper.py --url "https://www.youtube.com/@채널명" --max 10 --sort popular --format xlsx
